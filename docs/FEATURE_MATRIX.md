# Feature matrix

What GTO Wizard and Lucid Poker offer, and where this app stands. Gathered 2026-11-01 from public
pages: Lucid's App Store listing and trade-press / review coverage of GTO Wizard. Re-verify against
the sites themselves (you have accounts), since GTO Wizard's pricing in particular differs between sources.

| Capability | GTO Wizard | Lucid Poker | pokerlab |
|---|---|---|---|
| Pre-solved library (millions of spots) | Yes, Hold'em + PLO | Sim Browser on common flops | **Not replicated**: solve on demand + cache |
| Browse strategy grid / action tree | Yes | Yes | **Built** (13×13, reach-weighted, per-combo drill-down) |
| Custom solves | "GTO Wizard AI" (CFR + neural estimates, multiway) | Beta cloud re-solving of turn/river | **Built** (heads-up, TexasSolver) |

| Hand history analyzer | Upload histories, find leaks | Per-decision insights in drills | Planned |
| Daily quiz / engagement | Coaching content, PokerArena app | Daily Cardle | Planned (simple daily quiz from cached solves) |
| Preflop ranges + trainer | Yes (many formats incl. ICM/PKO) | Cash, Live, MTT, Spins | Planned (no open solver covers this well) |
| Multiway postflop | Yes (recent) | Not described | Out of scope for now |
| ICM / tournament | Yes | MTT ranges | Out of scope for now |
| PLO | Yes | Not described | Out of scope |
